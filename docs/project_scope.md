# 🔍 Project Scope

## 📌 Purpose

The purpose of this project is to build a personal finance data platform for tracking and analyzing household finances.

## ✅ In Scope
 - multiple bank accounts
 - income and expense transactions
 - transaction categories
 - account balances
 - transfers between accounts
 - historical financial analysis
 - reporting in Power BI

## ❌ Out of Scope

For the initial version:
 - automatic bank API integration
 - mobile application
 - multi-user access
 - cloud deployment

## 📥 Initial Data Sources

Data will initially be entered manually using Excel and VBA.

## 🚩 Target Output

The final solution will provide analytical reporting through Power BI based on data stored in SQL Server.
